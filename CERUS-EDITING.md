The dedicated page is `cerus-blacksite.html`, linked from the M4 Hybrid project. Its styles and interactions are isolated in `css/cerus.css` and `js/cerus.js`.

## Publishing

Set the Open Graph image URL in `cerus-blacksite.html` to the absolute deployed URL of `assets/cerus/lab-full.webp` once the GitHub Pages address is known. Add an absolute canonical URL at that point. Relative site links already support GitHub Pages project repositories.

Full-resolution WebP exports load only when a gallery image is selected. Standard page images are limited to 1920 pixels wide.
